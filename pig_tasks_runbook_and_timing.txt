PIG TASKS RUNBOOK (Container: 9cd2f8c34775)

Purpose
- Run Pig implementations for Tasks A-H.
- Store outputs in HDFS.
- Capture Pig timings in CSV.
- Compare Pig timings with existing MapReduce timings.

Files added in this project
- Pig scripts:
  - src/main/java/circlenet/taskA/taskA.pig
  - src/main/java/circlenet/taskB/taskB.pig
  - src/main/java/circlenet/taskC/taskC.pig
  - src/main/java/circlenet/taskD/taskD.pig
  - src/main/java/circlenet/taskE/taskE.pig
  - src/main/java/circlenet/taskF/taskF.pig
  - src/main/java/circlenet/taskG/taskG.pig
  - src/main/java/circlenet/taskH/taskH.pig
- Helper scripts:
  - run_pig_tasks_in_container.sh
  - compare_mr_pig_timings.sh

Important notes before running
- Task C Pig script is written as map-only style (FILTER + FOREACH + STORE only; no GROUP/JOIN).
- Task D/F/G/H Pig scripts avoid one-part-output assumptions and use safer relational flow.
- Task H Pig solution uses joins (no full distributed-cache table loading).

============================================================
2) Run all Pig tasks with timing capture
============================================================
Open shell in container:

   docker exec -it 9cd2f8c34775 bash

Inside container set input/output paths:

   export PAGES=/circlenet/pages/CircleNetPage.csv
   export FOLLOWS=/circlenet/follows/Follows.csv
   export ACTIVITY=/circlenet/activitylog/ActivityLog.csv
   export PIG_OUT=/circlenet/pig_output
   export PIG_TIMES=/home/ds503/pig_task_times.csv
   export HOBBY=PodcastBinging

Optional cleanup before fresh run:

   hdfs dfs -rm -r -f $PIG_OUT/taskA $PIG_OUT/taskB $PIG_OUT/taskC $PIG_OUT/taskD $PIG_OUT/taskE $PIG_OUT/taskF $PIG_OUT/taskG $PIG_OUT/taskH
   rm -f $PIG_TIMES

Run all Pig tasks (A-H):

   /home/ds503/run_pig_tasks_in_container.sh

What this script does:
- Runs each task script with `pig -x mapreduce`.
- Uses HDFS output path `/circlenet/pig_output/taskX`.
- Measures total elapsed ms per task.
- Appends to `/home/ds503/pig_task_times.csv` with columns:
  `timestamp,label,phase,time_ms,time_s,success`

============================================================
4) Compare MR vs Pig timings
============================================================
Prerequisite:
- MR timings already available at `/home/ds503/task_times.csv` (your existing file).
- Pig timings available at `/home/ds503/pig_task_times.csv` after step 2.

Generate comparison CSV:

   /home/ds503/compare_mr_pig_timings.sh

Output file:
- `/home/ds503/mr_vs_pig_comparison.csv`

CSV columns:
- task
- mr_label
- mr_time_ms
- pig_label
- pig_time_ms
- pig_minus_mr_ms

Interpretation:
- `pig_minus_mr_ms < 0` means Pig was faster.
- `pig_minus_mr_ms > 0` means MR was faster.

MR labels currently mapped in comparison script:
- A -> TaskAOptimized
- B -> TaskBOptimized
- C -> TaskCSimple
- D -> TaskDOptimized
- E -> TaskESimple
- F -> TaskFOptimized
- G -> TaskGOptimized
- H -> TaskHOptimized

If you want simple-vs-pig comparison for a specific task, edit label mapping in `/home/ds503/compare_mr_pig_timings.sh`.
