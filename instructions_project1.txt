1. Creating the Datasets: CircleNet Big Data Application
Here we need to write the code to generate the datasets that can later be loaded into the HDFS and then we can use that to write functions in mapreduce to perform analytics.
Here we are trying to create a dataset of a social media application named CircledNet.
We can divide the dataset into 3 separate files below:
    1A - CircleNetPage:
        Description: Here each line represents a person and should include at least the following attributes:
            A) ID: unique sequential number from 1 to 200,000
            B) NickName: characters of length between 10-20 (dont use commas inside this string) - Should sound like a nickname
            C) JobTitle: characters of length between 10-20 (dont use commas inside this string) - Should be realistic
            D) RegionCode: number (int) between 1 to 50
            E) FavoriteHobby: sequence of characters of length between 5 and 30 - Should be realistic
    1B - Follows:
        Description: each line describes a one-sided "follow" relationship from one-person to another and a timestamp indicating when this relationship was declared.
        Below are the attributes that we need:
            A) ColRel: unique sequential number (int) taken from value in the range from (1 to 20,000,000), basically "Follows" file will contain (20,000,000) lines
            B) ID1: ID of the person who has a CircleNetPage, which can be from (1 to 200,000)
            C) ID2: ID of the person who has a CircleNetPage, which can be from (1 to 200,000), but this should not be same as ID1.
                - Note for ID2: this is not a symmetric relationship; a follow relationship between person ID1 and ID2, is not same as relationship between person ID2 to ID1.
            D) DateOfRelation: Random number (int; sequential data type to use as date) between 1 to 1000000 to indicate when the follow relationship started.
            E) Description: It describes the type of relationship between the 2, explaining the reason to follow: college-friend, etc. be creative here, the limit of character length is 20-50 characters.
    1C - ActivityLog:
        Description: Each line indicates a person num1 has accessed or made an action on the CircleNetPage that belongs to a second person num2, including the timing of the access/action.
        Below are the attributes that we need for this dataset:
            A) ActionId: unique sequential number from 1 to 10000000
            B) ByWho: References the Id of the person who has access/made an action on the CircleNetPage
            C) WhatPage: References the Id of the page that was accessed.
            D) ActionType: text of characters length between 20-50 explaining if just viewed, left a note, poked, etc.
                Note that any action other than "viewed" should be preceded by a "viewed" action.
            E) ActionTime: random number between 1 to 1000000 (the granularity of the timestamp is the hour).
