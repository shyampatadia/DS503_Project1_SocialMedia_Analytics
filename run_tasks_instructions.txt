DS503 BDM - Analytics Jobs Run Instructions (Simple + Optimized)

0) One-time setup
   Build JAR (from project root):
   mvn clean package -DskipTests

   Copy JAR into container:
   docker cp target/ds503_bdm-1.0-SNAPSHOT.jar 9cd2f8c34775:/home/ds503/

   Inside container, set paths:
   export JAR=/home/ds503/ds503_bdm-1.0-SNAPSHOT.jar
   export PAGES=/circlenet/pages/CircleNetPage.csv
   export FOLLOWS=/circlenet/follows/Follows.csv
   export ACTIVITY=/circlenet/activitylog/ActivityLog.csv
   export OUT=/circlenet/output
   export LOCAL_OUT=/home/ds503/results
   export CIRCLENET_TIMING_FILE=/home/ds503/task_times.csv

   Optional reset before fresh benchmark:
   rm -f $CIRCLENET_TIMING_FILE
   rm -f $LOCAL_OUT
   hdfs dfs -rm -r -f $OUT/taskA $OUT/taskB $OUT/taskC $OUT/taskD $OUT/taskE $OUT/taskF $OUT/taskG $OUT/taskH
   mkdir -p $LOCAL_OUT

Task A
Run:
  hadoop jar $JAR circlenet.taskA.TaskA $PAGES $OUT/taskA/simple
  hadoop jar $JAR circlenet.taskA.TaskAOptimized $PAGES $OUT/taskA/optimized
Inspect:
  hdfs dfs -ls $OUT/taskA/simple
  hdfs dfs -cat $OUT/taskA/simple/part-r-00000 | head -20
  hdfs dfs -cat $OUT/taskA/optimized/part-r-00000 | head -20
Copy to container local:
  mkdir -p $LOCAL_OUT/taskA
  mkdir -p $LOCAL_OUT/taskA/simple
  mkdir -p $LOCAL_OUT/taskA/optimized
  hdfs dfs -get $OUT/taskA/simple $LOCAL_OUT/taskA/
  hdfs dfs -get $OUT/taskA/optimized $LOCAL_OUT/taskA/
Copy to host:
  docker cp dadc9d47d16e:/home/ds503/results/taskA ./results_taskA

Correctness check (recommended after each task)

   hdfs dfs -get -f $OUT/taskX/optimized /tmp/taskX_optimized
2) Compare canonicalized files:
   cat /tmp/taskX_simple/part-* | sort > /tmp/taskX_simple.txt
   cat /tmp/taskX_optimized/part-* | sort > /tmp/taskX_optimized.txt
   diff -u /tmp/taskX_simple.txt /tmp/taskX_optimized.txt
