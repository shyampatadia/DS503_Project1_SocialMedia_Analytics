Task 1:
Report the frequency of each favorite hobby

Here the dataset that will be needed is the CicleNetPage

The simple SQL query will be:
Select FavoriteHobby, COUNT (*) as count
From CircleNetPage
Group By FavoriteHobby.

Basic framework to understand any hadoop query is
Mapper: Transforms Input -> Intermediate Key/Value pairs
Reducer: Aggregates values per Key


Now there is a concept in Hadoop known as Combiner -> which is nothing but Mini-Reducer -> which is local reducer before the shuffling and sorting part.

Main Concept in Hadoop we need to understand its working is:
1. Its batch oriented, so here we dont run a function per se, we submit a job.
2. Very simplified view of how hadoop handles and executes a query:
    A. Reads HDFS
    B. Runs Mappers - User has the control on what mapper does
    C. Shuffles Data - Handled internally by MapReduce engine, User has no control.
    D. Runs Reducers - User has the control on what reducer does
    E. Writes outputs to HDFS


Now how the code development works: (Keeping in mind our docker image and container setup)
1. IntelliJ Idea - where we develop our Java Code
2. Docker Container:
    A. HDFS is installed
The workflow of execution:
1. We write the Java Code in our IDE (IntelliJ Idea).
2. JVM complies it and creates a Jar file -> meaning our IntelliJ will create a JAR file.
3. JAR file is then copied into the Container
4. Hadoop runs JAR - basically it runs compiled Java code inside the container.

Now we will create a directory structure in the HDFS file system:
1. Making base project directory: hdfs dfs -mkdir /circlenet
2. Below we will create 3 folders using the following commands:
hdfs dfs -mkdir /circlenet/pages
hdfs dfs -mkdir /circlenet/follows
hdfs dfs -mkdir /circlenet/activitylog

Then we will put the csv files in those directories:
hdfs dfs -put data/CircleNetPage.csv /circlenet/pages/
hdfs dfs -put data/Follows.csv /circlenet/follows/
hdfs dfs -put data/ActivityLog.csv /circlenet/activitylog/

We can verify if the rows are appropriately loaded for each file we can use following commands:
First 5 rows: hdfs dfs -cat /circlenet/follows/Follows.csv | head -5
Last 5 rows: hdfs dfs -cat /circlenet/follows/Follows.csv | tail -5
